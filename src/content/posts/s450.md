她的名字叫“雪野千代子”。她虽然是个成绩优异、认真踏实的学生，但不知为何，每周五下午总会跑来保健室偷懒。而——
我现在的身上，正穿着她的内裤。至于我为什么会有她的内裤，说来话长就先略过不提了，但今天特意穿过来，就是因为知道她会来这里。一边在胯间穿戴着她本人的下裤，一边和她聊着无关痛痒的闲话，这种背德感令人欲罢不能。一面微笑着，一面在心中肆意凌辱眼前女孩内裤的兴奋感。
这样的周末，已经持续了整整两年多……

通过在自己的内裤上附魔（Enchant）目标的爱液即可发动。可以使目标在梦境中醒来（消耗 30 WP）。

UI 与操作说明
(1) 好感度
影响附魔速度以及兴奋度上升速度等属性。
(2) 睡眠度
会随着对话或行动而上下浮动。降至 0 时角色可能会醒来，并导致游戏结束（Game Over）。
(3) 附魔（Enchant）
将各类下裤的湿润程度显示为 WP（湿润值 / Wet Point）。使用技能时会消耗 WP。
(4) 脱衣 / 体位变更点
对衣服或身体的特定部位点击右键并拖拽（上/下/左/右），可以将其脱下或变更姿势。此外，部分对象（被子、裙子、张腿角度等）可以通过右键 + 鼠标滚轮进行无缝调节（详情请参阅附带的 ReadMe 文件）。
